はじめに：この教材を書いた本当の理由

セールス代行の依頼が自分に集まり、受けきれなくなっている現状

質問例: 石田さん、最近セールス代行の依頼ってどれくらい来ているんですか？

  1. どんな人から依頼が来るか（講座を持つコンテンツホルダー、コミュニティのメンバーなど）
  2. 依頼が来る理由は、セールスチームの立ち上げ・監督を15案件やってきた実績と、紹介の連鎖
  3. 自分が直接入れる面談の枠には限りがある（準備・面談・報告まで含めると1日にこなせる数は決まっている）
  4. 断るしかなかった案件の中に、商品もよく、売れる見込みが十分あるものが多かった【実例】
  5. 「売れる商品があるのに、売る人がいない」という状態がもったいないと感じている

断るしかなかった案件を、信頼できる仲間に任せたい

質問例: 受けきれない分を、なぜ「仲間」に任せようと思ったんですか？

  1. セールスを外注したいクライアントは多いが、安心して任せられる人がなかなか見つからない
  2. セールス代行は人柄と倫理観がそのまま出る仕事。誰にでも紹介できるわけではない
  3. 自分のやり方と基準を共有した人なら、安心してクライアントに紹介できる
  4. チーム立ち上げで未経験の受講生を育ててきたので、型があれば未経験でも戦力になると知っている
  5. 仲間が増えれば、クライアントも、代行する人も、自分も全員が得をする

この教材で手に入るもの

質問例: この教材を読むと、具体的に何が手に入るんですか？

  1. セールス代行という仕事の全体像（報酬の仕組み、案件の取り方、面談1件の流れ）
  2. 押し売りにならないセールスの考え方
  3. 面談の5ステップと、そのまま使える質問・トーク・切り返し
  4. 報告書や連絡文のテンプレート（特典）
  5. 学んだあと実際の案件につながる、マッチングサロン

こんな人に向いている／向いていない

質問例: どんな人に読んでほしいですか？逆に、向いていない人は？

  1. 向いている: 自分の商品はまだないが、収入とスキルを同時に手に入れたい人
  2. 向いている: 自分の講座を持っているが、セールスに苦手意識がある人
  3. 向いている: 人の話を聞くのが好きで、誰かの役に立ちたい人
  4. 向いていない: 楽して稼ぎたい人、売れれば何を言ってもいいと考える人
  5. 向いていない: 練習や振り返りをせず、結果だけを早く欲しい人

著者プロフィールと実績

質問例: 改めて、石田さんのセールスの経歴を教えてください。

  1. 20代前半、高額学習教材の訪問販売からスタート。全国64支店・年商100億円規模の組織で800名中30位
  2. 最年少で支社長に昇進し、支社の売上を1.6倍に
  3. 50万〜130万円の高額講座のセールスで、1人で年間1億円
  4. 在籍200名のコミュニティ（PLC）で延べ200名をコンサル。録画から長所と弱点を見抜く指導で、成約率10%から40%に上がった人が100名以上
  5. セールスチームの立ち上げ・監督が15案件。プロデュースした60万円の心理系商品は、広告集客で1か月1,600万円、成約率50%、ROAS 2,200%

第1章 なぜ今、あなたのビジネスに「セールス代行」が必要なのか（前半を無料）

売上の不安に悩むコンテンツホルダーと、副業組のリアル

質問例: セールス代行に興味を持つ人って、今どんな状況の人が多いですか？

  1. コンテンツホルダー: 集客はできても個別相談で売れず、売上が安定しない
  2. 副業組: 会社以外の収入が欲しいが、何から始めればいいかわからない
  3. 両方に共通するのは、「売る力」がないまま走っていること
  4. 逆に言えば、売る力さえ身につけば状況は一気に変わる

「自分の商品作り」から始めると、収益化まで時間がかかるという現実

質問例: 自分の商品を作って売るのではダメなんですか？

  1. 商品作り、集客、セールスを全部1人でやると、最初の売上までに時間がかかる
  2. 商品作りに時間をかけても、売る力がなければ売れない
  3. セールス代行なら、すでに集客できている案件から始められる
  4. 収入を作りながら、売れる商品の条件を内側から学べる
  5. 自分の商品は、代行で売る力と市場感覚をつけてからでも遅くない

収入の安定と「売る力」を同時に手に入れる最短ルート

質問例: なぜセールス代行が「最短ルート」なんですか？

  1. 成約ごとに報酬が発生するので、成果がお金として早く返ってくる
  2. 毎回の面談が、そのまま実践練習になる
  3. いろいろな商品とお客様に触れるので、短期間で経験値がたまる
  4. 訪問販売時代に身につけたスキルが、その後、どう役にたったか？【石田実例】
  5. 売る力は一度身につければ、どんな業界・商品にも持ち運べる

図解候補: 「自分の商品から始める道」と「セールス代行から始める道」の比較

購入特典：セールス代行案件マッチングサロン参加券

質問例: マッチングサロンって、具体的に何ができる場所なんですか？

  1. セールス代行の案件紹介（石田さんが受けきれない案件など）
  2. メンバー同士のロープレ練習
  3. 面談の録画を持ち寄っての振り返りと相談
  4. 成約事例・失注事例の共有
  5. 同じ仕事をする仲間とのつながり（1人で悩まなくていい）

案件紹介の流れと条件

質問例: サロンに入ったら、すぐ案件を紹介してもらえるんですか？

  1. すぐには紹介しない。サロンに入ったら、まず練習会や勉強会に積極的に参加してもらう
  2. 練習会での取り組みを見て、「この人なら任せられる」と石田が判断した人に紹介する
  3. 紹介の基準はスキルだけでなく、学ぶ姿勢と継続して参加しているかどうか
  4. 商品と代行者の相性を見てマッチングし、クライアントとの顔合わせと契約へ進む

参加できる期間と、参加費の有無

質問例: 参加券で、いつまで参加できるんですか？

  1. 期間は
  2. 案件を紹介しても、石田は紹介料を受け取らない。報酬は代行者とクライアントの間で決める
  3. 紹介料を取らない理由（仲間を増やすことが目的だから）
  4. サロン内で守ってほしい行動基準（強引な売り方をしない、など）

有料部分

第2章 収入とスキルが同時に手に入る、セールス代行のポテンシャル

自分のビジネスを始める前の、最高の予行演習になる

質問例: セールス代行が、自分のビジネスの練習になるってどういうことですか？

  1. 人の商品を売ると、売れる商品と売れない商品の違いが見える
  2. お客様の悩み・言葉・反論を生で大量に聞ける。これが自分の商品作りの材料になる
  3. 価格・オファー・特典が成約にどう効くかを体感できる
  4. 自分の商品を出すときに、最初から「売れる確率」の高いものが作れる

業界が変わっても使える販売スキルが身につく

質問例: セールスのスキルって、ほかの業界でも通用するんですか？

  1. 学習教材の訪問販売、高額講座、心理系商品と、商品が変わっても同じ型で売れた【実例】
  2. 売れる理由は商品知識より、相手の悩みを聞いて整理する力
  3. ヒアリング、提案、クロージングの流れは業界が変わっても同じ
  4. 人の決断を後押しする仕事は、AIが進んでも残りやすい
  5. 会社員として働く場合でも、営業・採用・交渉などで一生使える

報酬の仕組み（成果報酬型、固定報酬＋成果報酬型、時間単価型の違い）

質問例: セールス代行の報酬って、どういう決まり方をするんですか？

  1. 成果報酬型: 成約金額の何%という決め方。料率は案件ごとに違う
  2. 固定報酬＋成果報酬型: 面談1件ごとの固定費に、成約時の歩合を足す
  3. 時間単価型・月額型: 稼働時間や月単位で契約する
  4. 未経験のうちに向いている型と、慣れてから交渉すべき型
  5. 返金が出たときの報酬の扱いは、契約前に必ず決める（第9章で詳しく）

収益シミュレーション：商品単価×成約率×面談数で考える

質問例: 実際のところ、どれくらい稼げるものなんですか？

  1. 収入は「商品単価×成約数×報酬率」で決まる
  2. 成約数は「面談数×成約率」。一番効くのは成約率を上げること
  3. 計算例（仮・1成約あたりの報酬5万円）
月の面談数稼働時間成約率40%のとき成約率20%のとき
15件約30時間6成約で30万円3成約で15万円
30件約60時間12成約で60万円6成約で30万円
  1. 成約率が20%か40%かで、同じ面談数でも収入は2倍変わる（PLCでは成約率10%から40%に上がった人が100名以上）
  2. 収入の保証ではなく、前提条件つきの目安として話す

稼働時間の目安：面談1件あたりの準備・実施・報告

質問例: 面談1件に、実際どれくらい時間を使うんですか？

  1. 準備・面談・報告を合わせて、1件あたり約2時間が目安
  2. 事前準備（申込内容の確認、台本の見直し）
  3. 面談本番と、面談後の報告・フォロー連絡
  4. 月30件なら約60時間、月15件なら約30時間。副業ならどのくらい回せるか
  5. 慣れると準備は短くなる。最初の数件は1件ずつじっくりやる

図解候補: 収入の計算式、成約率20%と40%の収入比較グラフ

第3章 未経験でも仕事になりやすい理由と、最初の案件の取り方

「売るのが苦手な起業家」は身近にいる

質問例: セールス代行の需要って、本当にそんなにあるんですか？

  1. 講座を作った人の多くは、教えるのは得意でも売るのは苦手
  2. 集客できても成約できず、広告費が無駄になっている人もいる
  3. 売れている人ほどセールスに手が回らなくなる。チーム立ち上げの依頼が来るのはこの段階【実例】
  4. 需要は、起業塾やコミュニティ、SNSで発信している人の周りに沢山ある

人間関係とコミュニティで立ち回り、依頼が来る人になる

質問例: 営業しなくても依頼が来る人って、何をしているんですか？

  1. まずはコミュニティの中で役に立つ人になる（質問に答える、手伝う）
  2. セールスを学んでいること、代行していることを周りに伝えておく
  3. 小さな実績を見える形にする（ロープレの感想、成約報告）
  4. 依頼してくれた人を成功させると、紹介が生まれる
  5. 石田の事例【実例】

最初の1件を取るための声のかけ方

質問例: 実績ゼロの人は、最初の1件をどう取ればいいですか？

  1. 声をかける相手の選び方（個別相談をやっているが、手が回っていない人）
  2. 声かけの文例（「個別相談の一部をお手伝いさせてもらえませんか」など）
  3. 相手のメリットを先に伝える（時間が空く、売上の取りこぼしが減る）
  4. 断られても関係を壊さない引き方
  5. サロン経由なら、最初の1件のハードルが下がる

実績ゼロのうちにできる「お試し期間」や「モニター価格」の出し方

質問例: 最初は無料でやるべきなんですか？

  1. 無料である必要はない。期限と件数を区切った「お試し期間」にする
  2. 成果報酬のみにして、クライアントのリスクを下げる
  3. 成果が出た場合、実績として紹介してよいという許可をもらう

受けてはいけない案件の見分け方

質問例: どんな案件なら断ったほうがいいですか？

  1. 自分が惚れ込めない商品、お客様が結果を出せていない商品
  2. 誇大な表現や強引な売り方を求められる案件
  3. 返金やクレーム対応のルールがあいまいな案件
  4. 集客ができておらず、面談がほとんど入らない案件
  5. 報告や改善提案に、クライアントが耳を貸さない案件

図解候補: 案件を受ける前のチェックリスト（受ける／断るの判定表）

第4章 「セールス＝怖い・押し売り」の思い込みを外す

セールスは押し売りではなく、悩みを解決する仕事

質問例: 「セールス＝押し売り」というイメージは、どう変えればいいですか？

  1. 押し売りは売り手の都合が起点。セールスはお客様の悩みが起点
  2. お客様は悩みがあるから、個別相談に申し込んでいる
  3. 面談の役割は、悩みを整理して、解決の選択肢を示すこと
  4. 合わない人には「合わない」と伝えるのもセールスの仕事

すらすら話せなくていい。成約の8割は「聞く力」で決まる

質問例: 口下手な人でもセールスはできるんですか？

  1. 売れない人ほど、話しすぎている
  2. 面談で、お客様と自分が話す割合の目安（石田さんの基準で）
  3. 聞くことで、お客様自身が自分の悩みに気づく
  4. 口下手な人ほど、聞く姿勢で信頼されやすい
  5. PLCで録画を見て、聞き方を変えただけで成約率が上がったケース【実例】

自分が心から惚れ込んだ商品だけを売ればいい

質問例: 売る商品は、何でもいいわけではないんですか？

  1. 自分が信じていない商品は、言葉や表情に出る
  2. 惚れ込めるかの判断基準（受講生の実績、講師の人柄、お客様の声）
  3. 商品を自分で体験したり、受講生に話を聞いたりする
  4. 惚れ込んでいると、クロージングに罪悪感がなくなる
  5. 惚れ込めない案件は、断る勇気を持つ

クロージングは、お客様を「現状維持」から救い出す行為

質問例: 最後に背中を押すのって、強引になりませんか？

  1. 何も決めないことも、「現状維持を選ぶ」という決断
  2. お客様が本当に望んでいるのは、今の状態から変わること
  3. 決断を後押しすることと、押し付けることの違い
  4. 最終的に決めるのはお客様、という線は必ず守る
  5. 「あのとき背中を押してもらってよかった」と言われた事例【実例】

「売れなくてクライアントに迷惑をかけたらどうしよう」という重圧の手放し方

質問例: 未経験だと、売れなかったときのプレッシャーが怖いと思うんですが。

  1. 最初から全部売れる人はいない。クライアントもそれはわかっている
  2. 結果の数字だけでなく、面談の中身を報告すれば信頼される
  3. 失注も「お客様の生の声」として、クライアントにとって価値がある
  4. 未経験の受講生をチームに育てたとき、全員が最初にぶつかった壁がここだった【実例】
  5. 不安は練習量で減らせる。ロープレの数で自信をつける

断られたときの受け止め方

質問例: 断られると落ち込むと思うんですが、どう切り替えていますか？

  1. 断られた＝自分を否定された、ではない
  2. 断られる理由は、タイミング・お金・相性などさまざま
  3. 断られた面談こそ、振り返りの材料になる
  4. 次の面談の前にやる、気持ちの切り替え方
  5. 訪問販売で何度も断られる中で学んだこと【実例】

図解候補: 押し売りとセールスの比較表、面談での話す割合の円グラフ

第5章 準備編：初回面談までに整えること

必要な環境とツール

質問例: セールス代行を始めるのに、何をそろえればいいですか？

  1. Zoom（録画の設定、プランの確認）
  2. 面談予約カレンダー
  3. 顧客管理シート（申込内容、面談結果、フォローの状況）
  4. 静かな場所と、カメラ・マイク・照明・適切な背景・服装
  5. 決済リンクや申込フォームなど、クライアントから共有してもらうもの

商品を理解するための、クライアントへの質問リスト

質問例: 案件を受けたら、最初にクライアントに何を聞きますか？

  1. 誰の、どんな悩みを、どう解決する商品か
  2. 価格、支払い方法、分割の条件、返金の規定
  3. 実績やお客様の声（面談でどこまで話してよいか）
  4. よく出る質問と反論、過去の失注理由
  5. 言ってはいけない表現、約束してはいけないこと

売れる台本の作り方（クライアントの台本の受け取り方と、自分用への直し方）

質問例: 台本は、クライアントからもらったものをそのまま使えばいいんですか？

  1. 受け取ったら、まず全体の流れを把握する
  2. 自分の言葉に直す（読み上げに聞こえないように）
  3. 質問の部分を厚くする
  4. 台本は「話す順番のメモ」くらいでちょうどいい
  5. 面談のたびに台本を直して育てていく

第7章 よくある断り文句への切り返し集

「お金がない」

質問例: 「お金がない」と言われたら、どう返しますか？

  1. 「物理的に払えない」のか、「払う価値がまだ見えていない」「懸念不安が残っている」のかを分ける
  2. 支払い方法の選択肢を案内する（分割、入学金＋分割 など）
  3. 生活費や借入金で払わせない線を、こちらから伝える
  4. 価値が伝わっていない場合は、本人の理想と得られる変化に話を戻す
  5. 本当に払えないなら、下位の商品（ダウンセル）や時期をずらす提案をする

「時間がない」

質問例: 「時間がない」と言われたらどうしますか？

  1. 1日や1週間に必要な時間を、具体的に伝える
  2. 今の時間の使い方を一緒に見直す
  3. 時間がない状態こそ、本人が変えたい現状ではないかを確認する
  4. 同じように忙しい状況から始めた人の事例
  5. 本当に無理なら、無理だと伝える

「家族に相談したい」

質問例: 「家族に相談したい」と言われたら？

  1. 本人のやる気を確認する（「ご家族のことを除けば、やりたい気持ちで間違いないですか？」）
  2. 家族が気にしそうな点（お金、時間、効果）過去相談した時の反応、家族の性格や傾向を聞く
  3. 家族に説明しやすい材料を渡す（費用、期間、返金の条件）
  4. 家族同席の三者面談を提案する
  5. 回答の日時を決める。家族への相談を妨げることはしない

「他と比べたい」

質問例: 「ほかのサービスと比べたい」と言われたら？

  1. 比べるのは当然のことだと認める
  2. 何を基準に比べるかを一緒に整理する
  3. 比較のポイント（サポート、実績、自分との相性）を示す
  4. ほかのサービスを悪く言わない
  5. 比べた上で選ばれる、という自信を持つ

「自分にできるか不安」

質問例: 「自分にできるか不安」と言われたら？

  1. 不安の中身を具体的に聞く
  2. 似た状況から結果を出した人の事例
  3. どんなサポートが受けられるかを伝える
  4. 最初の一歩を具体的にする
  5. できない理由を、一つずつ一緒につぶしていく

「少し考えたい」（保留の本音の見抜き方）

質問例: 一番多い「少し考えたい」には、どう対応していますか？

  1. 「大事な決断なので、考えていただいて大丈夫です」とまず受け止める
  2. 迷っている理由を選択肢で聞く（お金、続けられるか、内容が合うか）
  3. 理由がはっきりしないまま時間を置くと、気持ちが薄れやすいことを伝える
  4. 理由がわかれば、その場で答える
  5. 持ち帰る場合は、回答の日時を決めておく

それでも無理に押さない、という線引き

質問例: どこまで押していいのか、線引きを教えてください。

  1. 自分の中で「引くライン」を決めておく
  2. 不安をあおる、人格を否定する、家族への相談を妨げる、はすべてNG
  3. 強く押した契約はキャンセルになりやすい
  4. 「また相談したい」と思ってもらえる終わり方をする
